# Zimop (May-Be-Operations)
# Version 1.0
#
# Zimop is mandatory in RVA23.  It defines 40 instructions that are HINTs
# today (no architecturally visible state change) and may be redefined by
# future extensions.  mop.r.N takes rd and rs1, mop.rr.N takes rd, rs1 and
# rs2; the index N is baked into the fixed bits of each encoding (it is an
# opcode selector, not an operand, so no dedicated field is needed):
#   mop.r.N : 1 N[4] 00 N[3:2] 0111 N[1:0] rs1 100 rd 1110011
#   mop.rr.N: 1 N[2] 00 N[1:0] 1    rs2  rs1 100 rd 1110011
